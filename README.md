# Jira_Notes


1. What is Jira?  
   Product management tool   
* Track Project Work status  
* Track Bugs and Issues   
* Team work and time tracking


2. Need of Jira  
* One stop solution for project management  
* No need to make excel or other documents  
* Project work and bugs can be managed easily  
* Team can communicate over the project  
* Can handle multiple projects
